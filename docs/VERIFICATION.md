- 새로고침 후 풀이 복구, 시험 답안 저장·중단·재개·이전 답안 복구, 제출 전 정답 비공개와 제출 후 일괄 채점 확인.

- 320px 미리보기에서 문서 너비와 콘텐츠 뷰포트가 모두 305px로 일치해 가로 넘침 없음. 390px 모바일 화면과 기본 데스크톱 화면도 확인함.
- 개발 갱신과 분리한 최종 프로덕션 빌드의 새 브라우저 탭에서 콘솔 오류 **0개** 확인.

- DB 테스트는 중복·버전 변경, 가져오기 실패의 원자성, 불변 버전과 기존 답안 보존, 부분 점수, 수동 수정 후 복습 재계산, 시험 지연 채점, 답안 ID 재사용 차단, revision 충돌, RLS 사용자 격리, 익명/직접 쓰기 차단, 백업 반복 복원과 타임스탬프 보존을 검증함.
- 저장소 테스트는 백업 충돌의 원자성 및 손상된 체험 기록을 초기화하지 않고 원본을 보존하는 동작도 검증함.

실제 Supabase 프로젝트와 GitHub 저장소가 제공되지 않아 이메일 전달·실서비스 인증·Supabase 네트워크 왕복·GitHub Pages 게시 완료를 검증했다고 주장하지 않습니다. SQL과 공개 환경변수를 설정한 뒤 README의 최종 연결 절차를 실행해야 합니다. PWA 홈 화면 설치는 실제 모바일 기기에서 최종 확인해야 합니다.
